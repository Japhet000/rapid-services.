# Rapid Services 3.5.10 — Modification des employés

- Le gérant peut modifier le nom et l’adresse e-mail d’un employé existant.
- Validation de l’adresse e-mail côté serveur et gestion du conflit d’adresse déjà utilisée.
- Les changements de statut et l’activation/désactivation restent gérés côté serveur.
- Aucune suppression de compte ni migration destructive n’est ajoutée par cette version.

À tester sur une base de préproduction avant déploiement.
